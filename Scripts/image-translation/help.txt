Aidoku page translation host (pipeline, Apple Silicon macOS 15+)

Usage:
  swift Scripts/image-translation.swift [options] IMAGE|FOLDER ... [--list FILE]

Runs the app's pipeline (Aidoku/Core/Translation/Pipeline)
on Mac: S1 layout || S2 detect, S3 recognize, S4 group, S5 translate,
S6 mask, S7 inpaint, S8 style, S9 layout, S10 paint.

Modes (default: live)
  live                         S5 calls the real provider through PipelineTranslation and
                               RemoteTranslationClient with the mandatory page settings
                               (page image attached, SFX and background filtering on).
  --replay-translations DIR    S5 reads saved translations: a legacy run with
                               page-index.json, or a pipeline run with pages/*.json. No LLM.
  --ocr-only                   S1-S4 (plus the S8 style estimate); writes recognized
                               blocks. No LLM, no render.

Inputs
  IMAGE|FOLDER                 images or folders (non-recursive; png/jpg/webp/heic/...)
  --list FILE                  JSON array of paths or {"page_id","image_path"} objects,
                               or a text file with one path per line (relative paths
                               resolve against FILE's folder)
  --split dev|train|test       pages of the canonical grouped-source split
                               (test: run once at the end, never for selection)
  --manifest FILE              split manifest (default: the canonical manifest)
  --limit N                    first N pages after selection
  Repeated files are run once; repeated page ids get -2, -3, ... suffixes.

Output
  --output DIR                 default ../output/image-translation/run-<UUID>
  --no-png                     skip final PNG encoding
  --jobs N                     pages in flight, 1...64 (AIDOKU_IMAGE_JOBS; default 3)
  --writers N                  concurrent PNG/JSON writers (default 2)
  --reading-direction D        rightToLeft (default), leftToRight, topToBottom
                               (AIDOKU_READING_DIRECTION)
  --print-settings             print the resolved non-secret settings and exit
  Writes DIR/pages/<page>.json (blocks, lines, placement, timings, failure),
  DIR/pages/<page>.png (final page; not in --ocr-only) and DIR/summary.json.
  Exit status: 0 all pages finished, 1 a page failed, 2 invalid settings or another error.

Provider (live mode)
  --base-url URL               AIDOKU_TRANSLATION_BASE_URL
  --model NAME                 AIDOKU_TRANSLATION_MODEL
  --protocol P                 responses | chatCompletions (AIDOKU_TRANSLATION_PROTOCOL;
                               default chatCompletions)
  --reasoning R                modelDefault|none|minimal|low|medium|high|xhigh|max
                               (AIDOKU_TRANSLATION_REASONING)
  --timeout SECONDS            AIDOKU_TRANSLATION_TIMEOUT (default 60)
  --source LANG                auto|ja|zh-Hans|zh-Hant (AIDOKU_TRANSLATION_SOURCE; default auto)
  --target LANG                AIDOKU_TRANSLATION_TARGET (default ko)
  --key-env NAME               variable holding the API key (AIDOKU_TRANSLATION_KEY_ENV;
                               default AIDOKU_TRANSLATION_API_KEY)
  --credential-generation N    AIDOKU_TRANSLATION_CREDENTIAL_GENERATION (nonsecret)
  --allow-local-http           plain HTTP to loopback only (AIDOKU_TRANSLATION_ALLOW_LOCAL_HTTP)
  --provider-concurrency N     concurrent page requests, capped at 3 like the app
                               (AIDOKU_TRANSLATION_CONCURRENCY)

Replay evaluation
  --replay-fill-unmatched      give unmatched blocks a placeholder so S6-S10 run on all
  --translate-delay-ms N       hold S5 for N ms (models a provider wait)

Settings precedence: CLI arguments > shell environment > the repository's ignored
.env (AIDOKU_ENV_FILE=PATH reads another file; AIDOKU_ENV_FILE= disables it) >
defaults. The API key is never printed or written to output.

Build: the launcher compiles an incremental -O binary in build/image-translation-host
(AIDOKU_PIPELINE_CACHE overrides; AIDOKU_HOST_BUILD_ONLY=1 builds and exits).
Scoring: python3 Scripts/pipeline/eval.py RUN_DIR --split dev
