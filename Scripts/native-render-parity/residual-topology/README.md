# Frozen residual topology parity

Run `python3 Scripts/native-render-parity/residual-topology/run.py` from the worktree. The runner builds the actual production `NativeResidualTopology.swift` unchanged with strict Swift 6, extracts the six immutable browser policies from the archived manifest-verified oracle, and compares 146 independent fixtures exactly.

The five requested policies and the adjacent attached-leading-ink guard all have successful and rejecting fixtures. Coverage includes 8-connected diagonal lettering, singleton specks, large continuous contours, repeated attached protrusions, fractional and out-of-bounds rectangles, duplicated work-budget exhaustion, invalid buffers, truthy safe bytes versus strict `1`, detached and in-place foreign repaint, source font fallback, auxiliary boxes and scaled coordinates. Speck fixtures compare every RGBA, safe-mask and luminance byte, cached-proof invalidation, revision increments and complete undo; opaque flat-ring admission, nonflat/alpha rings, large connected tails, boundary-connected components, half-up rounding, and the browser's permissive short luminance buffers are exercised.

The only browser transport stub is `putImageData`, counted separately; no flood, color, luminance, mask, coverage or foreign-repaint algorithm is mocked. This verifies these policies and their raster mutations; whole-page glyph rasterization and final-image equality remain separate checks. Reports and actual/oracle outputs are under `build/native-render-parity/residual-topology`.

Actual iOS app execution was confirmed in BUILD24: **`NativeResidualTopologyTests` passed 5/5** on the arm64 iPhone 17 Pro simulator running iOS 26.5, using the Release `Aidoku` scheme and `AidokuFull` test plan. Together the topology and final-trial suites passed 10/10. Evidence: [BUILD24 summary](../../../build/native-render-parity/build24-tests-summary.json), [execution log](../../../build/native-render-parity/implementation-tests-24.log), and [tracked execution proof](../final-restoration-trial/ios-execution-proof.json).

The selected run as a whole **failed**: 30 tests passed and the strict final-image parity test failed on differing decoded RGBA pixels. Passing these policy suites does not certify final images as identical. Production final-trial caller integration and whole-page pixel validation remain separate pending gates.
