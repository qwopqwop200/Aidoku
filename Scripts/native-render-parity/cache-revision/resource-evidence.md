# Resource and timing evidence limits

Actual runtime coverage comes from one iOS simulator, UDID `AA441ADA-456B-41F8-B643-ECBF93AC0718`, with screen scale3. This is not physical-device, multi-device, low-memory-pressure or long-duration leak testing.

The production texture session is scoped to one render and closed through `defer`. Its immutable-source cache admits a cumulative maximum12,000,000 source texels. At RGBA8 that is48,000,000 logical payload bytes; this excludes Metal allocation alignment/driver overhead and retained CGImage/provider bytes. Output allocations independently reject more than12,000,000 pixels or an axis exceeding16,384 pixels. Source textures, output textures, CPU background/result Data, source artwork, restoration scratch, CoreText and PDF buffers can coexist. Those per-operation limits are not an overall process memory limit.

The decoded reader bitmap cache starts with32MiB and adapts up to192MiB according to reported available memory, retaining3–7 nearby pages. Encoded render assets have a separate16MiB LRU and native plans a2MiB LRU. Asset reads have two admission slots; encodings have four slots. Clearing a reader session cancels tracked work and releases retained cache entries; individual tasks/graphics drivers can finish releasing their resources later. Pixel counts and byte-cost accounting do not establish measured peak RSS or a no-OOM/no-leak guarantee.

The actual53 log records44 tests in9 suites finishing test bodies after45.335 seconds, with three strict parity issues still failing. The full16-image native/frozen-WebKit gate alone took42.309 seconds. Xcode reports57.735 seconds from testing-start to testing-complete, and the wrapper reports131.0 seconds overall including build/startup/test handling. These are test-run timings, not native render latency benchmarks, and there is no comparable pre-migration baseline. A separate build-only duration is not established by this log, so none is inferred by subtraction. No speedup, energy reduction or measured peak-memory improvement is claimed.

The actual53 canonical-backing suite passed two declarations/three cases and the texture primitive suite passed six declarations. Region analysis establishes exact RGBA outside the actual minified mask in four alpha captures; it does not establish complete alpha-render parity.
