# Keep-all item width and centered inline placement

This is an independent source/eligibility audit for Typography's existing 144-case hosted macOS capture. It reuses immutable captures, with no app changes, new simulator work, or fresh matrix. Run `python3 Scripts/native-render-parity/text-item-width-source/report.py` to write `build/native-render-parity/text-item-width-source/eligibility-report.json`.

The actual capture explicitly selects `white-space:pre; word-break:keep-all`, a 200px centered block at authored left 10.140625px, the existing Apple SD Gothic Neo bold face, four font sizes, and three tracking values. The older capture omitted word-break and therefore measured a separate normal policy; it is retained as `web-normal-break-control.json`. Exact word-item origins are 144/144 in the keep-all corpus. Canvas accumulation still has one ULP residual for `To` at fractional font size/negative spacing; no universal Canvas equivalence is claimed.

## Source arithmetic

[Inline layout units](https://github.com/WebKit/WebKit/blob/dd5fe1011df7e3438ac4889356abcab7681df46d/Source/WebCore/layout/LayoutUnits.h#L39) are Float, independent of quantized block geometry. [InlineItemsBuilder](https://github.com/WebKit/WebKit/blob/dd5fe1011df7e3438ac4889356abcab7681df46d/Source/WebCore/layout/formattingContexts/inline/InlineItemsBuilder.cpp#L788) caches widths of individual items with trailing-space optimization enabled. Keep-all preserves non-space fragments as units and emits separate whitespace items; ordinary word-break uses a different opportunity scanner.

[TextUtil](https://github.com/WebKit/WebKit/blob/dd5fe1011df7e3438ac4889356abcab7681df46d/Source/WebCore/layout/formattingContexts/inline/text/TextUtil.cpp#L65) measures a non-space item together with its next ASCII space when kerning/shaping is enabled, then subtracts the measured space plus word spacing. It clamps that item before placement. This differs from measuring the entire row as one string. The pinned preserved-whitespace path uses ordinary tracked text measurement; the newer cached TextUtil source has a different single-space condition and must not silently replace this revision.

[FontCascade](https://github.com/WebKit/WebKit/blob/dd5fe1011df7e3438ac4889356abcab7681df46d/Source/WebCore/platform/graphics/FontCascade.h#L159) measures a space through its ordinary text-width path. Default non-speed rendering enables kerning/shaping. [WidthIterator](https://github.com/WebKit/WebKit/blob/dd5fe1011df7e3438ac4889356abcab7681df46d/Source/WebCore/platform/graphics/WidthIterator.cpp#L839) accumulates natural advances first and applies CSS spacing afterward, per character with nonzero base advance. The one-glyph-per-scalar case reduces to the existing Float helper; complex clusters do not.

[Line append](https://github.com/WebKit/WebKit/blob/dd5fe1011df7e3438ac4889356abcab7681df46d/Source/WebCore/layout/formattingContexts/inline/InlineLine.cpp#L482) accumulates item widths in source order. [TextOnlySimpleLineBuilder](https://github.com/WebKit/WebKit/blob/dd5fe1011df7e3438ac4889356abcab7681df46d/Source/WebCore/layout/formattingContexts/inline/TextOnlySimpleLineBuilder.cpp#L103) closes the line before computing alignment. [Alignment](https://github.com/WebKit/WebKit/blob/dd5fe1011df7e3438ac4889356abcab7681df46d/Source/WebCore/layout/formattingContexts/inline/InlineFormattingUtils.cpp#L211) uses half the positive remaining Float width, then adds the containing line's Float origin.

## Bounded consumer eligibility

Apply this measurement only to actual private keep-all line-flow provenance with matching pre/pre-wrap semantics. It is an alignment-width substitution, not a change to glyph positions, line breaks, or client/scroll metrics. Require centered LTR identity-scale text, no word spacing or autospace, no authored forced line breaks, no authored leading/trailing whitespace, and at most one ASCII interword space. Natural shaping must preserve exact source indices, one glyph per scalar, identity run matrices, finite advances, and the same painted glyph/font instances.

A genuine soft nonfinal pre-wrap row may exclude its hanging trailing space from alignment. A final or forced-break row conditionally hangs only if its trailing content overflows; do not strip it unconditionally. The corpus does not exercise authored final trailing space. The existing helper's ASCII normalization is harmless only inside the narrow single-space eligibility boundary.

Decline normal/strict text, legacy whole-word paths, controlled blocks, preformatted rows, repeated preserved spaces, tabs, segment breaks, NBSP, ideographic/zero-width spaces, bidi formatting, clusters/ligatures, and color fonts. Their item boundaries, state, or whitespace semantics require separate proof. Clamp each extended item after subtracting space; clamping only the final row sum is a different policy.
