# Final restoration trial parity

`python3 Scripts/native-render-parity/final-restoration-trial/run.py` builds the actual production policies unchanged and executes the archived browser late balloon-safe-fit and short-caption blocks unchanged. Frozen files are SHA-checked against the original manifest. The 56 fixtures cover both successful and rejected admission, all preflight gates, transparent repaint foreign ownership, speck mutation, residual completion/refusal, the quarter-glyph fill cap, actual mask-based candidate glyph fitting, layout-parent lifting and rejection, detached proposal commit/rollback, and the three-search cap.

Comparison is exact for every RGBA/safe/luminance byte, proof-cache fields, surface revisions, undo, callbacks in order, proposal connection/provisional status, style output and budget counters. Glyph rectangles are supplied fixture measurements and tested against the actual independent safe-mask gate; DOM parenting and the external residual-fill callback are transport fixtures. This does not claim platform glyph raster equality or reverify the separate residual-fill algorithm. Production callers must use actual shaped glyph measurement, complete layout snapshots, retained transparent restoration canvases, and matching source metadata.

`python3 Scripts/native-render-parity/final-restoration-trial/run-app-tests-host.py` runs the two actual app Swift Testing suites (ten tests), removing only the app import for standalone host compilation. The same suites are registered in `AidokuFast.xctestplan` for root's exclusive iOS build. Reports are under `build/native-render-parity/final-restoration-trial` and `.../final-restoration-trial-app-tests`.

`python3 Scripts/native-render-parity/final-restoration-trial/run-margin.py` separately verifies the exact initial and group-recheck early-margin blocks: 31 cases compare every coverage/crop/core coordinate and glyph size as well as acceptance, including chromatic glyph exemptions, inherited-pixel rechecks, attached leading ink, invalid bounds, cropped scales, empty intersections and source-font fallback. Padding is an explicit caller geometry contract; the high-level caller must supply the frozen source-font/ink-frame padding formula.

Actual iOS app execution was confirmed in BUILD24: **`NativeFinalRestorationTrialTests` passed 5/5** on the arm64 iPhone 17 Pro simulator running iOS 26.5, using the Release `Aidoku` scheme and `AidokuFull` test plan. Together the topology and final-trial suites passed 10/10. Evidence: [BUILD24 summary](../../../build/native-render-parity/build24-tests-summary.json), [execution log](../../../build/native-render-parity/implementation-tests-24.log), and [tracked execution proof](ios-execution-proof.json).

The selected run as a whole **failed**: 30 tests passed and the strict final-image parity test failed on differing decoded RGBA pixels. Passing these policy suites does not certify final images as identical. Production final-trial caller integration and whole-page pixel validation remain separate pending gates.
